开源的 macOS 中文输入法 · 0.4.0

你打的字、说的话，都不出这台 Mac。

出字门不

二狗输入法的本体没有网络权限。它靠的不是一句“我们不上传”，而是 macOS 的沙盒根本不让它联网。拼音、五笔、本机语音输入都在；每一次联网，都记在你看得见的地方。

输入法本体，没有网络权限

系统不让它联网。

输入法看得到你的每一次按键，也听得到你说的话。所以二狗把它关在院子里：ErgouIME.app 开着 macOS 的 App Sandbox，没有申请任何网络权限，想联网也联不出去。

这不需要你相信谁。安装包签了名，权限写在签名里，谁都能查。在终端里运行右边这一行，看看输出里有没有 network.client。

本机语音输入

点一下右 Option，开口说。

再点一下结束。声音在这台 Mac 上识别，文字直接打进你正在用的输入框。边说边出字的是 SenseVoice，最后定稿的是 Qwen3-ASR 0.6B，两个模型都通过 sherpa-onnx 在本机运行。

  • 录音只在内存里。识别完就丢掉，不存盘，不上传。
  • 我的词。把人名、产品名、术语告诉它，识别时就按你的写法来。
  • 自动整理，可选。用 Apple 的设备端模型把口语理顺。云端模型也能用，但要你自己打开、自己填 Key。

联网记录

每一次联网，都记在账上。

平时能联网的只有旁边那个“设置”程序：你点“下载”时去取模型和词库，每天问一次有没有新版本（可以关）。它发出的每一个请求都写进 设置 › 联网记录：时间、用途、服务器、发出了什么、结果如何。只记数量和字数，不记内容。

记录保留最近 1000 条，可以清空。想换个角度核对，在终端运行 nettop，或者用 Little Snitch、LuLu 这类防火墙看二狗的连接。

打字

先得是个顺手的输入法。

默认是拼音，也可以五笔和拼音混着打。引擎是 Rime 的 librime，外面包了一层原生的 macOS 外壳，装好就能用，不用写配置文件。

把词库带过来

从搜狗、QQ、百度或 Rime 导出的 .txt 词库，或者一份纯词表，都能导入成个人词库。macOS 的“文本替换”可以一键变成常用语。导入只在本机读你选的那一个文件。

可选下载的词库

拼音大词库用的是雾凇拼音，约 89 万词，14.7 MB；还可以再加腾讯词库，多 98 万词。都要你点了“下载”才下载，弹窗里写明大小、来源和许可证。

    列表里还没有的话，注销再登录一次。

  3. 跟着新手引导走一遍

    第一次切到二狗会弹出引导：选拼音还是五笔拼音混输，按需下载词库和语音模型，导入原来输入法的个人词库，试一下语音。每一步都可以跳过。

隐私是怎么做到的

把能联网的和看得见你打字的，分成两拨。

二狗由四个程序组成，全都开着 App Sandbox。碰得到按键和麦克风的，没有网络权限；有网络权限的，平时碰不到你打的字。只有你打开了云端整理，它才会收到识别出的文字，以及光标前最多 200 字的上文（这一项可以关）。

程序网络权限做什么
输入法本体ErgouIME.app 没有 打字、录音、本机语音识别、候选窗、上屏
本机整理ErgouIMECorrector.xpc 没有 用 Apple 设备端模型或本机模型整理语音结果
设置程序ErgouIME Settings.app 有 设置界面；你点“下载”时下载模型和词库；检查和下载更新
云端整理ErgouIMECloud.xpc 只能发出连接 默认不用。只有你选了“云端模型”并填了 API Key，才把识别出的文字发给你选的服务

它不做这些

  • 没有遥测，没有统计 SDK，不上报使用数据
  • 从不读剪贴板
  • 录音不存盘、不上传
  • 密码框里不录音、不出候选、不学习
  • 日志不记你打的字和识别结果
  • 不做云同步，词库和设置都留在本机

只在这三种时候联网

  1. 你点了“下载”。语音模型、拼音大词库、整句模型，下载后校验 SHA-256。
  2. 检查更新。每天最多一次，向 api.github.com 发一个请求，不带你的任何输入和设置。可以关。
  3. 云端整理。默认关闭。打开后会边说边把识别出的文字发给你选的服务，录音从不发送。介意就别开。

自己核对

查签名里的权限：

codesign -d --entitlements - ~/Library/Input\ Methods/ErgouIME.app

仓库里的 scripts/check-no-network.sh 会检查源码和签名后的权限。完整的说明，包括数据存在哪里、怎么删干净，都写在 PRIVACY.md。

问答

常被问到的。

这里没有的，到 GitHub Issues 问。

免费吗？

免费。

开源吗？

开源，许可证是 GPL-3.0，代码在 github.com/codamon/ergou-ime。

Intel 的 Mac 能用吗？

能。安装包是 Universal 的，Apple 芯片和 Intel 都支持，系统要 macOS 13 Ventura 或更新。

会不会上传我打的字？

不会。输入法本体没有网络权限，系统层面就联不了网，也没有遥测。唯一会把文字发出去的是云端整理：它默认关闭，要你自己打开并填 API Key。打开后，它发送语音识别出的文字，默认还带上光标前最多 200 字的上文（可以关；密码框、终端和密码管理器里从不取）；录音本身从不发送。

语音输入要联网吗？

识别不联网。语音模型需要先下载一次，由设置程序在你点“下载”之后去取，这次下载也会记在联网记录里。

和 Rime、鼠须管是什么关系？

打字引擎用的是 Rime 的 librime，和鼠须管是同一个引擎。二狗是另一个独立的输入法：自己的 macOS 外壳和设置界面，加上本机语音输入，词库用雾凇拼音和极点五笔 86。

以前用搜狗，词库能带过来吗？

能。在 设置 › 输入 › 个人词库 里导入搜狗、QQ、百度或 Rime 导出的 .txt 文件，或一份纯词表。

有手机版或 Windows 版吗？

目前只有 Mac。

怎么卸载？

发布页附带 uninstall.sh，运行 bash uninstall.sh 即可；加上 --all 会连设置、词库和模型一起删掉，删之前先列出目录再问你。

遇到问题去哪儿说？

到 GitHub Issues 提。安全方面的问题请按仓库里的 SECURITY.md 私下报告。

In English

Ergou IME is a free, open-source Chinese input method for macOS. The input method itself runs in the App Sandbox with no network entitlement, so what you type and say cannot leave your Mac. Voice dictation is recognised on-device: tap Right Option, speak, tap again. Only the companion Settings app goes online, for downloads you ask for and a daily update check you can turn off, and every request is listed in its network log. Requires macOS 13 or later, Apple silicon or Intel. GPL-3.0.
