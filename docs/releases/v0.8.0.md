# 二狗输入法 0.8.0

## 新功能

- **说中文出英文**：在 设置 › 语音 › 说中文出英文 录一个快捷键（比如点一下右 Command，或 ⌃⌥E）。用它开始说话，说的是中文，打出来的是英文；用平常的语音键说着说着改按它，这次也出英文。
  - 只在 自动整理 选了“云端”时能用，用的是你自己填的服务和 Key。
  - 说完把整段话发一次给模型，它会顺手去掉口头禅和改口前的话，写成自然的英文，不逐字直译；识别把英文词写成同音汉字时（“在你麦克风上运行”）按上下文还原成 Mac。长段话按句子切开同时发。
  - 产品名、人名的英文写法模型不知道时，加进“我的词”（比如 Ergou），翻译时会照着写。
  - 录音时语音条上显示“中→英”；翻译中按回车跳过，输入中文。翻译失败或超时也输入中文，并提示原因。
  - 英文结果不参与“从我的修改里学习”，也不加中英文之间的空格。
  - 在其他输入法下也能用（和语音键一样：单个修饰键需要“输入监控”权限，带 ⌃ ⌥ 的组合键不需要）。

## 隐私

- 说中文出英文发出的内容和云端整理一样（识别出的文字、App 名字、我的词、光标前的文字），只是改成说完后发一次；见 PRIVACY.md。联网记录里显示为“说中文出英文”。
