# 二狗输入法 0.8.1

## 修正

- **五笔调频太“健忘”**：同一个码有几个字时（比如 fcu 的 去、云），以前只看最近选了谁。去选过一百多次，偶尔选一次云，云就排到第一，去要再选七八次才回到前面。五笔靠位置盲打，第一位老变容易打错。现在按累计选过的次数排，次数一样才看最近选了谁。没选过的字仍然排在选过的后面。
  - 想换一个字当第一位，要选到和原来那个字次数一样多。
  - 只影响五笔打完整码时的候选；拼音、没打完的码和纠错候选的顺序不变。关掉“自动调频”时不起作用。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。设置和数据都保留，以前的调频记录接着用。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.8.1.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.8.1.pkg   # 应显示 accepted / Notarized Developer ID
```
