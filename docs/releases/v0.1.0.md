# 二狗输入法 0.1.0（首个公开测试版）

隐私优先的开源 macOS 中文输入法：五笔 86、五笔拼音混输、本机语音输入。输入法本体没有网络权限，打的字和说的话默认不出这台 Mac。

这是第一个公开版本，还在测试阶段，欢迎在 Issues 里反馈问题。安全问题请按 [SECURITY.md](https://github.com/codamon/ergou-ime/blob/main/SECURITY.md) 私密报告。

## 系统要求

- macOS 13 Ventura 或更新（本机大模型整理需要 macOS 13.3 或更新）
- Universal：Apple 芯片和 Intel 都能装（Intel 机器还没有真机测试过）
- 语音模型要另外下载：高精度模型压缩包约 879 MB（解压后约 985 MB，识别时占用内存 1.5～2.2 GB），轻量模型约 158 MB

## 安装

1. 下载 `ErgouIME-0.1.0.pkg`，双击安装。安装包有 Developer ID 签名并经过苹果公证；只装给当前用户（`~/Library/Input Methods/ErgouIME.app`）。
2. 打开“系统设置 → 键盘 → 输入法 → 编辑…”，点“+”，在“简体中文”里选 **二狗**。列表里还没有的话，注销再登录一次。
3. 切到二狗输入法，在菜单栏的输入法菜单里选“打开设置…”，到“语音”页**下载语音模型**。安装包里不带模型；点下载后会弹窗写明模型名、大小、来源和许可证，确认后才下载，下载后校验 SHA-256。
4. 第一次说话时，系统会询问**麦克风**权限。要在其他输入法下也能按右 Option 说话，还要在“系统设置 → 隐私与安全性 → 输入监控”里打开二狗输入法。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.1.0.pkg
# 3585a5ff93ef27d118a5c7bb3fc836a7223bb53a9fa0527d152d5a69f87668b5
spctl -a -vvv -t install ErgouIME-0.1.0.pkg   # 应显示 accepted / Notarized Developer ID
```

## 功能

- 五笔 86（极点码表），自动调频，不自动造词；手动造词、常用语（短码上屏）
- 五笔拼音混输：不用切换就能打拼音，拼音候选旁显示五笔码；模糊音、拼音容错、五笔空码容错；四码唯一自动上屏（选项，默认关）；先按 `` ` `` 只打拼音
- 只用拼音模式（整句、简拼、模糊音、容错、双拼）
- 语音：点一下右 Option 开始、再点一下结束，本机识别后直接上屏（Qwen3-ASR 0.6B 出最终结果，SenseVoice 边说边显示），认“我的词”；没有输入框时复制到剪贴板并提示
- 可选的识别后整理：Apple 设备端模型、本机模型，或云端模型（默认关闭；会发出什么见 [PRIVACY.md](https://github.com/codamon/ergou-ime/blob/main/PRIVACY.md)）
- Shift 中英切换、按应用记住中英文、中英之间自动加空格、计算器（`=1+2`）、日期（`rq`）、简繁切换、联想

## 隐私

- 输入法本体和本机整理进程没有网络权限（App Sandbox），可以用 `codesign -d --entitlements - ~/Library/Input\ Methods/ErgouIME.app` 自己查。
- 没有遥测；不读剪贴板；录音只在内存里，不存盘、不上传；密码框里不录音、不学习。
- 设置程序只在你点“下载”时联网。云端整理默认关闭，打开后才会把识别出的文字发给你选的服务。

## 卸载

下载附带的 `uninstall.sh`，在终端运行 `bash uninstall.sh`（只删程序，保留设置和模型）或 `bash uninstall.sh --all`（同时删除设置、词库、语音记录、模型和云端 Key，删除前列出并询问）。

## 已知问题

- 设置里的“检查更新”还没有做，新版本请到 Releases 页下载。
- 设置里还不能删除已下载的模型（可以删 `~/Library/Group Containers/<TeamID>.com.codamon.ergou/Models/` 下对应的文件夹）。
- 第一次安装后，系统可能要注销再登录才列出新的输入源。
