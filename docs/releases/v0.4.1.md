# 二狗输入法 0.4.1

修正版本。

## 修正

- **设置改了不生效**：每页候选个数、模糊音、容错、自动调频、整句模型、个人词库等，改完以后要等输入法重启（注销或重启电脑）才生效，比如候选个数选了 9 还是显示 5。原因是输入法重新部署时没有重启 Rime 引擎，引擎一直用着内存里的旧配置。现在每次部署都会重新初始化引擎，改完几秒内就生效。
- **新手引导的“详情”**：整行都能点，不用再瞄准小箭头；展开后的内容靠左对齐，过长的下载地址不再折行（鼠标悬停显示完整地址）。
- **设置窗口**：最小 640×560、最大 900×960，不会被拉得过窄挤在一起，也不会拉得过大满是空白。

## 输入法列表里有很多个“二狗”

如果“系统设置 › 键盘 › 输入法”里出现一串“二狗”，在终端运行：

```sh
curl -fsSL https://raw.githubusercontent.com/codamon/ergou-ime/main/scripts/repair-input-sources.sh | bash
```

然后注销重新登录。它不需要管理员权限，会清掉旧的登记和缓存，并在桌面生成一份诊断报告（不含你打过的字）；如果问题还在，可以把报告发到 GitHub Issues。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.4.1.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.4.1.pkg   # 应显示 accepted / Notarized Developer ID
```
