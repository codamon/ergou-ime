# 二狗输入法 0.5.0

这一版有四项新功能：从我的修改里学习、中英混输、反馈问题、删除语音模型。

## 从我的修改里学习

语音打出来的词不对，你改一次，二狗就记住；同样的修改出现两次，以后自动改对。

### 它怎么工作

语音结果打进输入框后，如果你在同一个输入框里把其中一个词改成了别的，二狗会记下“听成什么 → 改成什么”这一对词：

- **第一次**：只把改成的词当作提示，让更准的识别器以后更容易听对，不会自动替换任何东西。
- **同样的修改出现第二次**：以后的语音结果里，听错的词会被悄悄替换成你改成的词。
- **你把被替换的词又改回去**：这条规则就永远取消。
- 二狗在别的输入法下打字（自动切过来打）或把结果复制到剪贴板时，同样会替换，但那里的修改不会被跟踪，所以在那里改回去不会取消规则；要取消，在输入框里用二狗改回去一次，或在“我的词”里删掉这个词。

### 关闭和删除

- 开关在 设置 › 语音 › 语音记录 里的“从我的修改里学习”，默认打开。
- 学到的词会出现在 设置 › 我的词，标着“你改过”。在那里删掉一个词，它对应的词对也一起删掉。

### 数据存在哪、什么不会发生

- 存下来的只有“听成什么 → 改成什么”这一对词，放在输入法自己的私有目录里（`voice-corrections.json`），只在这台 Mac 上。
- 不上传，没有联网。从修改里学到的词只在本机当热词用，即使打开了云端整理，也不会发给云端。
- 语音打出来后，输入法在本机读这段文字，以及它前面约 16 个字、后面约 80 个字，最多 60 秒、每秒最多一次，只放在内存里，按回车、Tab、Esc、离开输入框、下一次语音或到 60 秒就丢掉。
- 密码框里从不读取、从不学习。

详细说明见 [PRIVACY.md](https://github.com/codamon/ergou-ime/blob/main/PRIVACY.md)。

## 中英混输

在拼音和五笔里直接打英文词：打 `github`、`python`，候选里就有 GitHub、Python（标准写法），按空格上屏，不用切换中英文。

- 和中文冲突时英文排第二：全拼里输入正好是完整的拼音音节（含模糊音），五笔拼音混输里正好是五笔码，中文排第一。
- 双拼也支持。
- 英文词库来自雾凇拼音（约 2.2 万个词）。

## 反馈问题

设置 › 关于 › 反馈问题…：先列出要附上的环境信息（版本、系统、设置开关、已装的模型），不含你打过的字、说过的话、词库、麦克风名称、云端地址和 Key。你确认后，才在浏览器里打开预填好的 GitHub 问题页，或者复制下来。

## 删除语音模型

设置 › 语音 › 模型 和 自动整理 里，已安装的模型多了“删除…”，确认框写明删除后的影响和能释放的空间。

## 其他改进

- 导入的个人词库在五笔拼音混输里也能用五笔打出来（开着“四码唯一自动上屏”时不加，避免破坏四码唯一）。
- 发版前会核对每个模型下载地址的 SHA-256，上游文件被替换时不会发出去。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.5.0.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.5.0.pkg   # 应显示 accepted / Notarized Developer ID
```
