# 二狗输入法 0.2.2

根据用户反馈的两处修改。

## 修改

- **每页候选个数可以调**：设置 › 输入 › 输入方式 › 每页候选个数，3～9 个（默认 5 个），按数字 1～9 选词。
- **菜单栏图标变大**：原来的图标只有 12×12 pt，比旁边的图标小一圈；现在是标准的 16×16 pt。

## 安装和升级

装了 0.2.1 的会自动收到更新提醒（每天最多检查一次），也可以在 设置 › 关于 里点“检查更新…”。0.2.0 和更早的版本要手动下载 `ErgouIME-0.2.2.pkg` 安装。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.2.2.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.2.2.pkg   # 应显示 accepted / Notarized Developer ID
```

## 已知问题

- 打字中途按数字会选对应的候选（和其他拼音输入法一样）；要打出数字，先按空格或回车上屏，再按数字。
- 反复安装后，“系统设置 › 键盘 › 输入法”里可能出现重复的“二狗”，注销重新登录可以恢复；不影响打字。
- 整句输入还没有语言模型（语法模型），长句偶尔会选错词。
