# 二狗输入法 0.6.1

修正 0.6.0 的一个已知问题：候选条右边的翻页箭头可以用鼠标点了。

## 修正

- **用鼠标点候选条右边的翻页箭头 ‹ › 可以翻页了**：以前箭头只是画出来，点了没有反应（点候选字一直可以）。点 › 到下一页，点 ‹ 回上一页；没有上一页或下一页时箭头是淡的，点了不动。键盘翻页照旧：左右方向键移到头自动翻页，上键翻回上一页，下键展开更多候选。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.6.1.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.6.1.pkg   # 应显示 accepted / Notarized Developer ID
```
