# 二狗输入法 0.6.3

两条用户反馈：切回二狗时应该是中文；中英混输里英文单词总排第一。

## 改动

- **切到二狗，从中文开始**：以前在二狗里按 Shift 打英文，切到别的输入法，再切回二狗想打中文，却还是英文，要再按一次 Shift。现在从别的输入法切到二狗，一律从中文开始。密码框会让系统自己切到英文再切回来，这种不算，原来是英文的还是英文。
- **英文和中文谁排第一，跟着上次的选择**：打拼音时把“问题”打成 `went`、“可以”打成 `key`，英文单词每次都排第一，选多少次中文也不变。现在在同一串按键上，上次选了中文，下次中文排第一；上次选了英文单词，下次英文排第一。只记“这串按键上次选的是中文还是英文”，不记选的词，只存在本机；关掉“自动调频”就不记，“清空调频记录”会一并删除。
- **中英混输可以关掉**：设置 › 输入 › 输入方式 里多了“中英混输”开关。关掉后候选里不再出现英文单词，要打英文按 Shift。

## 说明

如果打开了 系统设置 › 键盘 › 输入法 里的“自动切换到文稿的输入法”，切换窗口时系统把输入法换回二狗，也会从中文开始。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.6.3.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.6.3.pkg   # 应显示 accepted / Notarized Developer ID
```
