# 二狗输入法 0.2.3

## 修改

- **菜单栏图标再放大**：去掉黑色底板，直接用实心的狗头做图标，占满菜单栏给输入法图标的 22×16 pt，和旁边的微信等图标一样大。

## 安装和升级

装了 0.2.1 或 0.2.2 的会自动收到更新提醒（每天最多检查一次），也可以在 设置 › 关于 里点“检查更新…”。0.2.0 和更早的版本要手动下载 `ErgouIME-0.2.3.pkg` 安装。设置和数据都保留。装好后菜单栏还显示旧图标的话，切换一次输入法即可。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.2.3.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.2.3.pkg   # 应显示 accepted / Notarized Developer ID
```

## 已知问题

- 打字中途按数字会选对应的候选（和其他拼音输入法一样）；要打出数字，先按空格把候选上屏，再按数字。（Esc 会清掉没上屏的拼音，回车会把拼音字母原样上屏。）
- 反复安装后，“系统设置 › 键盘 › 输入法”里可能出现重复的“二狗”，注销重新登录可以恢复；不影响打字。
- 整句输入还没有语言模型（语法模型），长句偶尔会选错词。
