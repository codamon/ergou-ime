# 二狗输入法 0.7.1

0.7.0 发布后做了一次代码审计，这一版把查出来的问题都修了。

## 修正

- **语音键和中英切换键可能落到同一个键上，之后中英切不了**：比如语音键是 ⌃Space、中英切换是右 Option 时，点语音键的“恢复默认”，两个都成了右 Option，Shift 也不再切换。现在“恢复默认”和录制一样会检查冲突；设置里万一还是冲突，中英切换回到左右 Shift。
- **按住修饰键点鼠标，被当成“点了一下修饰键”**：语音键或中英切换键设成 Control、Command 这类单键时，⌃-点击、⌘-点击会误开始录音或切换中英。现在按住期间点过鼠标就不算。语音键是 ⌃Space、中英切换是 Control 时，按一次 ⌃Space 也不再顺带切换中英。
- **把应用移出“默认用英文的应用”后，已经打开的输入框还是英文**：现在回到中文。
- **快捷键不能只带 ⌘**：⌘Q、⌘C、⌘V 这类是应用自己的快捷键，录成语音键会把它们从所有应用里拿走。组合键现在要带 ⌃ 或 ⌥（或者是 F1～F20）。0.7.0 里录过只带 ⌘ 的组合键的，升级后回到默认，需要重新录。
- **组合键的语音键被别的程序占用时**：以前设置里仍显示能用，也不会再试。现在显示没能启动，之后改设置时会重新注册。
- **说完后再整理一遍全文（Beta）**：上限从 1500 字改成 600 字，等待时间按长度算（5 秒加每 50 字 1 秒），不再对长段话白等；按回车跳过分段整理后，不会再接着发全文。
- **在别的输入法下说话**：开着“语音记录”或“常用语”窗口时，不再把它们一起藏起来。
- 两个设置页里的快捷键冲突检查用的是最新的值，不会因为另一页刚改过而误判。
- 带冒号的键（比如 ⌃⇧;）可以录了。

## 内部

- 设置程序录制快捷键时让输入法暂停语音键的通知，现在要配合共享设置里的时间标记才算数，别的程序反复发这个通知不能再一直压住语音键。
- 发版检查除了核对镜像文件的大小，还核对 ETag；模型列表里有条目没被检查脚本读到时直接报错。
- `Shared/Privacy.swift` 第 11 条补上了“说完后再整理一遍全文”的那次额外发送；README 里关于快捷键的两处说明改成和实际一致。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.7.1.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.7.1.pkg   # 应显示 accepted / Notarized Developer ID
```
