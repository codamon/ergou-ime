# 二狗输入法 0.8.2

## 改进

- **按没有对应候选的数字，字母和数字一起上屏**：比如打 `mem` 出来 5 个候选，按 `0`（从来不是选字键），或者按 `6`～`9`，直接打出 `mem0`、`mem6`。以前按了什么都不会发生。
  - 数字后面有候选时照常选字，`mem2` 还是选第二个。
  - 拼音整句里已经选好的部分照样上屏：打 `nihaoma`、先选了“你好”再按 `0`，得到 `你好ma0`。
  - 计算器（`=12*30`）里的数字照常算进算式；`` ` `` 开头的输入上屏时去掉前缀。
  - 五笔和拼音都有。这样上屏的内容不记调频。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.8.2.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.8.2.pkg   # 应显示 accepted / Notarized Developer ID
```
