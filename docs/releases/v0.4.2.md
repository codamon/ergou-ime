# 二狗输入法 0.4.2

修正版本：修掉“输入法列表里出现很多个二狗”，加了卸载入口，并修正了对 0.4.1 代码做完整审计后查出的安全和隐私问题。

## 输入法列表里出现很多个“二狗”

原因查明了：macOS 27 把第三方输入法的启用状态记在新的列表里，而二狗的安装程序还手工往旧列表里写了一份，两份并存时系统会把二狗的输入模式列出很多次，每次重装都会复现。0.4.2 的安装程序在 macOS 27 及以上不再写旧列表，并清掉以前写进去的；更早的系统行为不变。

更新到 0.4.2 后注销重新登录一次即可。还没更新的，可以先运行修复脚本（会生成一份诊断报告）：

```sh
curl -fsSL https://raw.githubusercontent.com/codamon/ergou-ime/main/scripts/repair-input-sources.sh | bash
```

## 新增：卸载入口

设置 › 关于 › 卸载…：在访达里显示卸载程序，双击运行。默认保留设置、词库和模型；旁边的“卸载并删除全部数据”会先列出再询问。卸载时会把二狗从“已启用的输入法”里一并去掉。

## 修正

- **“清空调频记录”以前不起作用**：按钮点了什么都没删（从 0.1.0 起就是这样）。现在会真正删除 Rime 的用户词库，包括拼音模式记下的你打过的词。手动添加的词和导入的个人词库不受影响。
- **改设置后中/英状态被重置**（0.4.1 引入）：在终端等英文状态下改一次设置，会突然变回中文。现在重新部署后保持每个输入框原来的中/英状态。
- **清空类请求要验证来源**：以前本机任何程序发一个系统通知，就能清空语音记录、让输入法反复重新部署。现在这类请求必须由设置程序写进共享设置才执行；没有任何设置变化的重新部署请求不再重启引擎（持续不断的请求仍然会占用后台处理，但不再让输入法停在英文状态）。输入法没在运行时点的“清空”，下次启动时会补做。
- **模型和词库只加载自己校验过的副本**：语音模型、本机整理模型以前校验后直接从共享目录加载，校验和加载之间文件可能被换掉。现在先克隆进各进程自己的目录（原文件还在时不多占磁盘；模型删除后副本也会删除），校验副本，只加载副本。词库拷贝也改成按内容拷贝，不再可能留下软链接。
- **更新校验更严**：安装包除了核对 SHA-256、开发者签名和苹果公证，现在还必须是二狗本身、版本号和发布页一致且比当前版本新（以前同一开发者签名的旧版本也能通过）。核对期间关掉窗口不会再弹出安装器。
- **云端整理不再跟随跳转**：服务器返回跳转时，以前会把识别出的文字转发到另一个地址，而联网记录里记的还是原地址。现在直接拒绝跳转。
- **联网记录**：下载开始时就记一条，下到一半退出也查得到（云端整理的请求仍是结束时才记）；两个程序同时写不会丢条目；不打开联网记录页，文件也不会无限增长。
- **录音中途进入密码框**：立即停止并丢弃录音。
- **后台检查更新时“打开设置…”没反应**：现在会正常打开设置窗口。
- 其他：个人词库文件的几种异常情况（重复条目导致设置程序崩溃、Windows 换行的文件读不出、超大文件）；按键耗时日志降为调试级别，默认不再写入系统日志；修复脚本支持装在 `/Library/Input Methods` 的情况；安装脚本读不到系统输入法列表时不再继续改动。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.4.2.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.4.2.pkg   # 应显示 accepted / Notarized Developer ID
```
