# 二狗输入法 0.7.0

补上几样输入法都该有的东西：emoji 和符号、以词定字、拆字、竖排候选、能自己录的快捷键、默认用英文的应用名单。

## 新功能

- **emoji 和符号**：打词就出，排在对应的词后面。`xiao` → 笑 😄，`jiantou` → → ← ↑ ↓，`sheshidu` → ℃。拼音默认开，五笔拼音混输默认关（多一个候选会让后面的候选挪位），在 设置 › 输入 里开关。
- **以词定字**：字不好找时，打一个带这个字的词，按 `[` 上屏词的第一个字，按 `]` 上屏最后一个字。`chenmo` 再按 `]` 得到“默”。候选是英文、emoji、符号时，这两个键照旧打标点。可以关。
- **拆字**（拼音方案）：会写不会读的字，先按 `` ` `` 再打各个部件的拼音，`` `niuniuniu `` 得到“犇”，候选旁边注着读音。全拼和三种双拼都能用。
- **竖排候选**：设置 › 外观 › 排列。竖排时上下方向键移动候选。
- **快捷键自己录**：语音键（设置 › 语音）和中英切换键（设置 › 输入）都改成了录制框——点一下，按下想用的键，回车或点别处确认，Esc 取消。可以是单独一个修饰键（分左右：右 Option、左 Shift、Fn……），也可以是带 ⌃ ⌥ ⌘ 的组合键。默认不变：右 Option 说话，左右 Shift 切换中英。
- **默认用英文的应用**：设置 › 输入 里的名单，可以加减。默认是终端和代码编辑器（Terminal、iTerm、Warp、Ghostty、kitty、Alacritty、VS Code、VSCodium、Cursor、Zed）。已经记住中英状态的应用不受影响；把应用加进来或移出去，它就重新按名单来。
- **说完后再整理一遍全文**（Beta，云端整理，默认关）：话是按停顿一段一段整理的，说了一半停下、下一段又重说的内容以前去不掉。打开后，分成两段以上的话在说完后把整段再发一次，只去掉这种重说。每次说完要多等 1～2 秒，模型判断错时可能删掉想保留的一句，所以是个选项。

## 修正

- **在别的输入法下说话，文字打不进输入框**：在一些应用（比如 Electron 写的）里，说完话文字只进了剪贴板。现在能直接打进去。
- **语音键是组合键时不需要“输入监控”权限**，在别的输入法下也能用。语音键是单独一个修饰键时仍然需要；缺这个权限时，设置里会直接提示并打开系统设置的那一页，在二狗里用语音后也会提醒（每天最多一次）。以前点“允许…”第二次起没有反应。
- **万象整句模型从二狗自己存的原样拷贝下载**（`ergou-dl.signalhouse.nz`，Cloudflare R2）。作者会原地替换发布页上的文件，一替换，校验就不通过、装不上。内容和 SHA-256 与作者 2026-11-10 发布的文件相同，下载弹窗里同时写出原始来源。

## 说明

- 升级后第一次打字要重新部署一次（编译拆字码表），头几秒按键可能直接出英文。
- 符号是“打词出符号”，没有单独的符号面板；要翻找符号，用系统的 ⌃⌘空格。
- 五笔拼音混输里没有拆字：五笔本身就是按字形打的，`` ` `` 在五笔里是“只打拼音”。
- 语音键设成组合键、又没给“输入监控”权限时，在别的输入法下录音中按 Esc 取消不了，再按一次快捷键结束。
- 语音键设成 Fn 时，如果系统把 Fn 用来弹表情面板或切换输入法，要到 系统设置 › 键盘 把“按下 🌐 键时”改成“不执行任何操作”。

## 隐私

- 万象整句模型的下载请求发到 `ergou-dl.signalhouse.nz`（只放文件，没有统计，没有打开访问日志）；和访问任何网站一样，Cloudflare 会看到 IP 地址。其他下载仍然来自 GitHub Releases 和 Hugging Face。
- “说完后再整理一遍全文”打开时，整理好的全文会再发一次给你选的云端服务。默认关。
- 默认用英文的应用名单只存应用的标识符，在本机的设置里。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.7.0.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.7.0.pkg   # 应显示 accepted / Notarized Developer ID
```
