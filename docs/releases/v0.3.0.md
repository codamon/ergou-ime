# 二狗输入法 0.3.0

## 新增：整句模型（可选下载）

长句容易拼错，是因为整句只按词频挑词，不看前后搭配。现在可以在 设置 › 输入 › 词库和整句模型 里下载一个整句模型，按词与词的搭配挑整句。拼音和五笔拼音混输的拼音部分都会用上，五笔码的候选不受影响。

两个模型二选一（同时只能用一个，下载一个会替换另一个）：

| | 下载 | 实测整句全对 | 打字时内存 |
|---|---|---|---|
| 不用模型 | — | 65% | — |
| **轻量**（Rime 官方，推荐） | 41 MB | 81% | 多占约 40 MB |
| **万象** | 418 MB | 83% | ⚠️ 多占约 350 MB |

实测用的是 121 个日常分句，配拼音大词库。万象只比轻量略准，内存却多占很多，8 GB 内存的 Mac 建议用轻量。

和词库一样：确认后才下载，下载后校验 SHA-256；输入法把模型拷进自己的目录、再校验一遍才使用，然后删掉下载的原文件，只占一份空间。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。0.2.0 和更早的版本要手动下载 `ErgouIME-0.3.0.pkg` 安装。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.3.0.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.3.0.pkg   # 应显示 accepted / Notarized Developer ID
```

## 已知问题

- 打字中途按数字会选对应的候选（和其他拼音输入法一样）；要打出数字，先按空格把候选上屏，再按数字。（Esc 会清掉没上屏的拼音，回车会把拼音字母原样上屏。）
- 反复安装后，“系统设置 › 键盘 › 输入法”里可能出现重复的“二狗”，重启或注销重新登录可以恢复；不影响打字。
- 万象模型的下载地址是作者的滚动发布（LTS）；作者更新文件后会校验失败、不会装上，需要等二狗更新校验值。
