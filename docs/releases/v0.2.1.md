# 二狗输入法 0.2.1

修正几个问题，并加入自动检查更新。

## 修正

- 关掉设置窗口后，程序坞里的二狗图标不消失。现在关掉最后一个窗口，设置程序就退出。
- 从输入法菜单打开“关于”时，没有直接跳到关于页。

## 自动检查更新（默认打开）

- 你用输入法时，每天最多一次，由设置程序向 GitHub 查一下有没有新版本。只发一个请求，不带你打的字、设置或任何标识；输入法本体仍然没有网络权限。
- 没有新版本：什么都不显示。有新版本：弹出窗口（不抢键盘焦点），写明版本号、大小和更新说明，可以“下载并安装”“以后再说”或“跳过这个版本”。**你同意之前不会下载任何东西。**
- 同意后下载安装包，核对 SHA-256、同一开发者的 Developer ID 签名和苹果公证，全部通过才交给系统安装器，在安装器里再确认一次。设置、词库、调频记录和语音模型都保留。
- 在 设置 › 关于 里可以关掉自动检查，或点“检查更新…”手动查。

隐私说明已相应更新，见 [PRIVACY.md](https://github.com/codamon/ergou-ime/blob/main/PRIVACY.md) 的“什么时候联网”。

## 安装和升级

0.2.0 和更早的版本还没有更新功能，这一次要手动下载 `ErgouIME-0.2.1.pkg` 双击安装（直接覆盖，设置和数据都保留）。从 0.2.1 开始，以后的新版本会自动提醒。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.2.1.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.2.1.pkg   # 应显示 accepted / Notarized Developer ID
```

## 已知问题

- 反复安装后，“系统设置 › 键盘 › 输入法”里可能出现重复的“二狗”，注销重新登录可以恢复；不影响打字。
- 整句输入还没有语言模型（语法模型），长句偶尔会选错词。
- 设置里还不能删除已下载的语音模型（词库可以删）。
