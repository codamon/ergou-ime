# 二狗输入法 0.6.0

新功能：候选窗的样子可以自己选了。另外修了左右方向键在候选条上没有反应，以及语音整理结果里的两个问题。

## 新增：设置 › 外观

起因是用户希望候选窗有几个样子可选，字的大小也能调。

- **三套样式**
  - 玻璃（默认）：半透明，透出后面的颜色。
  - 实底：不透明，在任何屏幕上都最清楚。
  - 紧凑：半透明，间距和圆角更小，少占地方。
- **选中候选的颜色**：跟随系统的强调色，或者从蓝、紫、红、橙、绿、青、石墨里选一个。
- **字号**：14、16（默认）、18、20、24。序号和编码按比例跟着变。

页面顶部有一个候选窗示例，改设置时跟着变。改完马上生效，下次打字就能看到，不需要重新部署。

颜色没有开放成任意调色：0.5.1 重做候选窗就是因为序号太浅看不清，所以这里每一种搭配都实测过，文字对比度不低于 4.5:1。橙、绿、青配白字达不到，这三个颜色保持亮色，上面的字用近黑色。

系统的“降低透明度”或“增强对比度”开着的时候，候选窗仍然总是用实底。语音输入的提示条不跟这几项设置走。

## 修正

- **左右方向键可以在候选条上移动了**：以前按左右键没有反应。现在左右键移动高亮，移到头自动翻页，上键翻回上一页；下键仍然是展开更多候选。
- **语音整理结果里多出花括号**：比如说“网易八哥说”，上屏的是“网易{Bugo}说”。识别结果里本来没有花括号时，本机整理和云端整理多加的 { } 现在一律去掉。
- **云端整理偶尔把一小段话换成应用的名字**：比如一句话被整个换成“备忘录”。整理结果里出现了当前应用的名字、而识别结果里没有时，这次整理作废，用识别的原文。
- **“从我的修改里学习”的诊断记录**：每次语音上屏，在本机系统日志里记一条是否开始跟踪修改、没跟踪的原因和当前应用的标识，用来确认 Chrome、Slack、VS Code 这类应用里能不能学习。不记任何文字，不上传。

## 已知问题

- 用鼠标点候选条右边的翻页箭头没有反应（点候选字可以）。用键盘翻页，例如左右方向键移到头会自动翻页。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.6.0.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.6.0.pkg   # 应显示 accepted / Notarized Developer ID
```
