# 二狗输入法 0.2.0

这一版主要改拼音：拼音成了默认方案，并且可以下载更全的拼音词库。

## 新增和改动

- **拼音大词库**：设置 › 输入 › 词库 里可以下载[雾凇拼音](https://github.com/iDvel/rime-ice)词库（2026.06.30 版的字表、基础、扩展三份，约 89 万词，下载 14.7 MB）。原来自带的拼音词库只有约 8 万词，内卷、躺平、大模型这类新词和很多日常短语都没有，整句容易拼错。拼音和五笔拼音混输都用这个词库；没下载时照旧用自带的小词库。
- **腾讯词库（可选）**：装了拼音大词库后，可以再加雾凇附带的腾讯词库（约 98 万词，多是新词、专有名词和名称）。冷僻候选会多一些，重新部署也慢一点，所以默认不装。
- **拼音成为默认方案**。新安装默认是拼音；从 0.1.0 升级、原来用五笔拼音混输的，保持五笔不变。要换方案在“输入 › 输入方式”里改。
- `lue` 和 `lve` 都能打出“略”（`nue`、`nve` 同理）。

下载和校验方式和语音模型一样：确认弹窗写明来源、大小、SHA-256 和许可证（GPL-3.0），确认后才下载；输入法把词库拷进自己的目录、再校验一遍才使用，文件被改过就不用，退回自带的小词库。

## 安装和升级

下载 `ErgouIME-0.2.0.pkg`，双击安装（直接覆盖 0.1.0，设置、调频记录和模型都保留）。第一次安装的步骤见 [README](https://github.com/codamon/ergou-ime#安装)。装好后到设置 › 输入 › 词库 下载拼音大词库。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.2.0.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.2.0.pkg   # 应显示 accepted / Notarized Developer ID
```

## 已知问题

- 整句输入还没有语言模型（语法模型），长句偶尔会选错词，之后再评估。
- 设置里的“检查更新”还没有做，新版本请到 Releases 页下载。
- 设置里还不能删除已下载的语音模型（词库可以删）。
