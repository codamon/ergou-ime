# 二狗输入法 0.6.2

修正：升级二狗时不再每次都弹出“系统设置 › 键盘”。

## 修正

- **升级时不再弹出“键盘”设置页**：以前每装一次新版本，系统设置的“键盘”页就会自己打开。原因是安装程序每次都会请系统“启用二狗”，而在 macOS 27 上，对已经启用的输入法再请求一次，系统就会打开这个页面。现在已经启用的就不再请求；第一次安装时照旧启用。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.6.2.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.6.2.pkg   # 应显示 accepted / Notarized Developer ID
```
