# 二狗输入法 0.4.0

三个新功能：让换过来更容易，让隐私看得见。

## 新手引导

第一次切到二狗时弹出（不抢正在打字的焦点），四步，都可以跳过：

1. 选输入方式：拼音，或五笔拼音混输。
2. 一键下载推荐组合：拼音大词库、轻量整句模型、高精度和轻量语音模型。每一项都写明大小、来源、许可证和 SHA-256，点“下载”后依次下载、校验。
3. 导入原来输入法的个人词库。
4. 语音输入说明和试打框。

以后可以在 设置 › 关于 › 打开新手引导 重新打开。从旧版升级的用户也会看到一次，已经装好的项目会标“已安装”。

## 导入个人词库

设置 › 输入 › 个人词库 › 导入…（新手引导里也有），把原来攒下的人名、公司名、专业词搬过来：

- 搜狗、QQ、百度、Rime 导出的 .txt 词库，或者每行一个词的文本（UTF-8、UTF-16、GBK 都行）；
- macOS“文本替换”导出的 .plist，会加进常用语，快捷键就是编码。

带拼音的保留拼音，只有词的按单字读音自动注音（多音字的几种读法都能打）。只收纯汉字的词；搜狗的 .scel / .bin 是二进制格式，请先在搜狗里导出成 .txt。文件只在这台 Mac 上读取，不上传。设置程序为此多了一项沙盒权限：只读取你在打开面板里选的那个文件。

## 联网记录

设置里新增“联网记录”页：二狗的每一次联网都记在这里，包括时间、用途、服务器、发出了什么（只记数量和字数，不记内容）、收发字节数和结果。输入法本体没有网络权限，从不出现在这里。想独立核对，可以用 `nettop` 或 Little Snitch、LuLu 这类防火墙。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。0.2.0 和更早的版本要手动下载 `ErgouIME-0.4.0.pkg` 安装。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.4.0.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.4.0.pkg   # 应显示 accepted / Notarized Developer ID
```

## 已知问题

- 打字中途按数字会选对应的候选（和其他拼音输入法一样）；要打出数字，先按空格把候选上屏，再按数字。
- 导入的词只进拼音词库；五笔拼音混输里可以用拼音打出来，但没有五笔编码。
- 反复安装后，“系统设置 › 键盘 › 输入法”里可能出现重复的“二狗”，重启或注销重新登录可以恢复；不影响打字。
