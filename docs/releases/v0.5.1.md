# 二狗输入法 0.5.1

修正版本：候选窗重做。起因是用户反馈候选字前面的数字序号太浅，在颜色不准的显示器上完全看不到。

## 候选窗

- **序号、编码、翻页箭头看得清了**：以前用系统的淡色，叠在半透明背景上对比度只有约 1.6–2:1。现在不再靠调淡颜色来区分主次，改用字号和字重。在白色文档、深色编辑器、花哨背景、纯黑、纯白几种背景上实测，候选字最差 5.8:1，序号和编码最差 5.2:1。
- **选中项更明显**：以前是一层很淡的蓝底，现在是系统选中色的实底配白字，和菜单里的选中项一样，跟随你在系统设置里选的强调色。
- **macOS 26 及以上用 Liquid Glass**，更早的系统保留原来的毛玻璃。文字下面垫了一层底色，背景再花也不影响阅读。
- **跟随辅助功能设置**：打开 系统设置 › 辅助功能 › 显示 里的“降低透明度”或“增强对比度”，候选窗换成不透明底；增强对比度下描边更粗、文字更实。
- **低分辨率显示器上的锯齿黑边没有了**：以前候选窗外圈有一条 1 像素的硬黑边，在不带 Retina 缩放的显示器上，圆角处是一级一级的台阶。现在阴影和描边都是平滑的。

语音输入的提示条用了同一套规则。候选窗的布局、翻页、向下展开和鼠标点选都没有变，仍然没有任何动画。

## 说明

macOS 13–15 走的旧毛玻璃只在 macOS 27 上渲染检查过，没有在这几个老系统上实测。如果你在老系统上看到候选窗显示不对，请在 设置 › 关于 › 反馈问题 里告诉我。

## 安装和升级

装了 0.2.1 及以后版本的会自动收到更新提醒，也可以在 设置 › 关于 里点“检查更新…”。设置和数据都保留。

校验安装包：

```sh
shasum -a 256 ErgouIME-0.5.1.pkg   # 和附带的 .sha256 文件对照
spctl -a -vvv -t install ErgouIME-0.5.1.pkg   # 应显示 accepted / Notarized Developer ID
```
